# Local Website Preview

Just run:

    python main.py

The terminal will print:

    🔗 Local URL: http://127.0.0.1:5000
    🔗 Localhost: http://localhost:5000

Open that link in your browser.

This starts both:
- Flask website
- Telegram bot polling

To change the port:

    PORT=8080 python main.py

Then open:

    http://127.0.0.1:8080
